# Python Programming Journey

A structured collection of Python programs built while developing a foundation in programming, data structures, file handling, exception handling, and database connectivity.

This repository reflects a progression from core Python problem-solving to working with structured data and relational databases.

## Areas Covered

- Python fundamentals and list manipulation
- Random number generation
- CSV file handling
- Input validation
- Exception handling
- Stack data structures
- Functions and stack-based processing
- MySQL connectivity
- Database record management and retrieval

## Repository Structure

| Area | Focus |
|---|---|
| List Manipulation | Working with Python lists |
| Random Number Generation | Generating constrained random values |
| CSV Data Handling | Creating, searching and updating structured file data |
| Input Validation | Handling invalid user input |
| Exception Handling | Managing common runtime errors |
| Stack Data Structure | Push, Pop and Display operations |
| Stack Filtering | Processing strings with stack logic |
| Functions & Stack | Combining reusable functions with data structures |
| MySQL Data Management | Modifying relational database records |
| MySQL Data Retrieval | Querying and processing database records |

## Technologies

## Engineering Focus

The goal is to build strong fundamentals that can be applied to larger software systems:

- Writing readable and maintainable code
- Breaking problems into reusable functions
- Handling invalid input and runtime errors
- Working with structured data
- Understanding data structures
- Connecting applications with relational databases
- Building a foundation for backend and software engineering

This repository will evolve as I continue exploring software engineering, backend development, databases, and larger real-world projects.
